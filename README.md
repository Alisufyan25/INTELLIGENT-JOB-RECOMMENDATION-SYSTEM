

# Intelligent Job Recommendation System

An AI-powered Job Recommendation System developed using Python, Machine Learning, and Natural Language Processing (NLP). This project intelligently matches job seekers with relevant job opportunities using TF-IDF vectorization, PCA dimensionality reduction, and K-Nearest Neighbours (KNN) with cosine similarity.

## Features

* Job recommendation based on user skills and preferences
* TF-IDF feature extraction for semantic text analysis
* PCA dimensionality reduction for optimized performance
* KNN recommendation engine using cosine similarity
* Data preprocessing and text cleaning
* Advanced filtering and keyword search
* Evaluation metrics (similarity, coverage, diversity)
* Interactive data visualizations using Matplotlib and Seaborn
* Export recommendation reports to CSV

## Dataset

The project uses a Kaggle Job Postings Dataset containing:

* Job Titles
* Company Names
* Locations
* Job Levels
* Job Types
* Search Positions

## Workflow

1. Load Dataset
2. Data Cleaning and Preprocessing
3. Feature Engineering using TF-IDF
4. Label Encoding and Scaling
5. PCA Dimensionality Reduction
6. User Profile Transformation
7. KNN Recommendation System
8. Evaluation and Visualization

## Output

The system generates:

* Top 5 personalized job recommendations
* Similarity scores
* Analytical graphs
* CSV recommendation reports
